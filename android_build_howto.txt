To build:
1- Build the armv7 naive library:
docker build -f Dockerfile_armv7.android -t rustdesk-android-armv7 .
2- bash into the image:
docker run -it rustdesk-android-armv7:latest /bin/bash
3- run these commands to copy librustdesk.so and libc++_shared.so to suitable place in project
mkdir -p ./flutter/android/app/src/main/jniLibs/armeabi-v7a
cp ./target/armv7-linux-androideabi/release/liblibrustdesk.so ./flutter/android/app/src/main/jniLibs/armeabi-v7a/librustdesk.so
cp ${ANDROID_NDK_HOME}/toolchains/llvm/prebuilt/linux-x86_64/sysroot/usr/lib/arm-linux-androideabi/libc++_shared.so \
   ./flutter/android/app/src/main/jniLibs/armeabi-v7a/
4- without exiting the contaner, open new ssh session and copy librustdesk.so and libc++_shared.so from container to project
docker cp 9257f03fb5ff:/workspace/flutter/android/app/src/main/jniLibs/armeabi-v7a .

repeat these steps for thr arm64 docker. at the end the flutter/android/app/src/main/jniLibs has two folders armeabi-v7a and arm64-v8a both containing librustdesk.so and libc++_shared.so
